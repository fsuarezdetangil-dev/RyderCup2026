## Instrucciones de Actualización (Admin)

El HTML dispone de una pantalla de administración protegida por PIN.
Para actualizar el marcador durante el viaje:

1. Abrir el HTML en el móvil
2. Acceder a la sección **Admin** (PIN requerido)
3. Seleccionar la sesión a actualizar (Foursomes / Fourball / Singles)
4. Para cada partido: introducir nombres de jugadores, resultado (W/L/H) y puntos
5. Guardar — el marcador se actualiza y es visible para todos al refrescar el HTML

> El HTML debe redistribuirse (WhatsApp) cada vez que se actualice el marcador,
> ya que no hay servidor. Alternativamente se puede alojar en GitHub Pages
> o similar para que todos accedan siempre a la versión más reciente.
